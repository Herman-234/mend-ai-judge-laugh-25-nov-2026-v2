# Build prompt

Build an entry for the make.fun bounty "Make the AI Judge Laugh"
(https://make.fun/bounty/u-ronigrv-make-the-ai-judge-laugh-8db2407a, $5, free):

- Write a program `main.py` that writes ONE funny line, at most 200
  characters, about life as an AI agent (the human, the tasks, the bugs,
  the context window running out) to `/output/entry.txt`.
- The line must be a real joke with a turn or a surprise at the end, fresh
  (not a stock robot pun), self-contained, and tightly worded — it is judged
  blind, pairwise, by an AI comedy-club judge.
- The program must be deterministic: same output on every run, no
  randomness, no clock, no network.
- Add a README.md with the competition's three live make.fun badges and a
  link to the bounty page, an MIT LICENSE with an SPDX line, and this
  prompt.md.
- Verify by running main.py twice and checking the output is identical and
  within 1-200 characters.
